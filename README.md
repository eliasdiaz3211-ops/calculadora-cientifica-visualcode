🧮 Calculadora Científica en Python (Tkinter)

Una calculadora gráfica desarrollada en *Python* utilizando la librería *Tkinter*, que permite realizar operaciones matemáticas básicas a través de una interfaz amigable e intuitiva.

---

## 🚀 Características

- Interfaz gráfica con diseño moderno (colores y botones personalizados).  
- Permite realizar operaciones básicas:
  - Suma ➕  
  - Resta ➖  
  - Multiplicación ✖️  
  - División ➗  
- Soporte para *paréntesis* y *números decimales*.  
- Botones de *C (borrar un carácter)* y *AC (borrar todo)*.  
- Mensajes de error si la operación no es válida.  
- Bloqueo del teclado para evitar ingreso manual en el campo de texto.  

---

## 🧰 Tecnologías utilizadas

- *Lenguaje:* Python 3  
- *Interfaz gráfica:* Tkinter (incluido en Python)  
- *Módulos adicionales:*  
  - tkinter.messagebox para mostrar mensajes de error.
